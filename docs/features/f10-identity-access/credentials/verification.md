## Phạm vi và quyết định review

Own Identity V2 migration tạo app_user/account guard, digest/purpose/epoch/expiry/single-use tokens, durable local transition intent, HMAC throttle/capacity gate và append-only runtime audit. Không shared Java/domain JAR hoặc peer DB. JDBC runtime đã có R02b nay dùng thêm credential CLI; Flyway vẫn test-scoped và bootstrap/transport vẫn businessReady=false. Identity test migration namespace V20/V30 để không collide production V2; peer fixtures không đổi.

Reset/disable/enable/recovery commit pending intent cùng epoch/hash/token update. R03 không participant ACK/journal hoặc session authority; pending chặn verified callback. Lock order account → token, KDF ngoài connection/transaction, bounded DB lock2s/statement5s/connect1s/socket5s. Future R04 effect phải nằm trong callback sau locked reread, không coi KDF match là authorization độc lập.

Review tìm và sửa: token→account lock order có thể deadlock reissue/disable; hai new throttle keys có thể vượt cap nếu không serialize; direct enable sau recovery có thể dùng lại hash cũ; recovery có thể vô tình bỏ operator disable. Source hiện dùng user-first, advisory admission + DB hard-cap trigger, recovery clear hash và independent operator_disabled preserved. Fresh-reset required, enable recovery chỉ clear disable và không clear RECOVERY_REQUIRED. No source secret or runtime HTTP admin/browser endpoint.

Password15–128 Unicode code points, giữ nguyên whitespace/normalization, reject unpaired surrogate, >72-byte evidence. Argon2id v19 memory19456KiB/t2/p1/salt16/hash32; unsupported/malformed stored hash unavailable, không parse attacker-chosen memory/iterations. Corpus strict UTF-8/exact lines/version/source/CC0/SHA256/size cap, fixture không comprehensive production qualification. Two KDF slots/process và account/IP reservations trước KDF; no unbounded queue/new-key cap bypass. Crash reservations conservativeTTL, không permanent account lock; DB/KDF unavailable không bad-password count.
