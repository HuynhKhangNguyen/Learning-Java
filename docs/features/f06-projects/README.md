## Mục tiêu và phạm vi

Bắt đầu project khi đủ năng lực nền, ghi bằng chứng áp dụng của từng milestone.

Readiness khác hoàn thành; CL-U-01 R1 là áp dụng mô hình, chưa chứng minh Java project/runner.

- Module: MD01, MD05, MD07, MD09.
- Requirement: REQ-08,12; [định nghĩa và acceptance](../../product-requirements.md).
- Hợp đồng chung: [Readiness và bằng chứng đã áp dụng](../../business-design.md) / [feature–module](../../feature-module-map.md).

## Hiện trạng

CL-U-01 và readiness P/DP đã thiết kế; chưa runtime/applied evidence. [Trạng thái task hiện hành](../../delivery-backlog.md) là nguồn chuẩn; mô tả trong tài liệu thiết kế không tự là bằng chứng runtime DONE.
