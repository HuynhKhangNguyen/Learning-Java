# F03 — Luyện tập và feedback

[Mục lục feature](../README.md) · [Toàn bộ doc](../../README.md)

## Mục tiêu và phạm vi

Luyện với feedback, hint, lời giải và retry; ghi rõ mức hỗ trợ.

Luyện tập có hỗ trợ; kết quả luyện không tự thành pass kiểm tra độc lập.

- Module: MD03, MD04, MD09.
- Requirement: REQ-04,11,12; [định nghĩa và acceptance](../../product-requirements.md).
- Hợp đồng chung: [Quy tắc luyện tập, hỗ trợ và evidence](../../business-design.md) / [feature–module](../../feature-module-map.md).

## Hiện trạng

Case luyện Collections đã có ở thiết kế; runtime luyện mới chưa được nghiệm thu. [Trạng thái task hiện hành](../../delivery-backlog.md) là nguồn chuẩn; mô tả trong tài liệu thiết kế không tự là bằng chứng runtime DONE.
