# F04 — Kiểm tra và bằng chứng năng lực

[Mục lục feature](../README.md) · [Toàn bộ doc](../../README.md)

## Mục tiêu và phạm vi

Kiểm tra bằng tình huống mới, trả kết quả theo từng CAP và tiêu chí rubric.

Case/rubric, grading và evidence; không cấp pass từ Next, hint hoặc lời giải đã lộ.

- Module: MD04, MD05, MD09.
- Requirement: REQ-05,06,12,13; [định nghĩa và acceptance](../../product-requirements.md).
- Hợp đồng chung: [Business kiểm tra và bằng chứng năng lực](../../business-design.md) / [feature–module](../../feature-module-map.md).

## Hiện trạng

Rubric/case đã thiết kế; grading và evidence server thuộc task runtime còn PLANNED. [Trạng thái task hiện hành](../../delivery-backlog.md) là nguồn chuẩn; mô tả trong tài liệu thiết kế không tự là bằng chứng runtime DONE.
