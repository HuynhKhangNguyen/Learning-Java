Xem toàn cảnh Java Backend/DevOps, chọn mục có đường vào và biết vì sao được gợi ý.

Outline, prerequisite/readiness và Journey; không tự publish hoặc cấp bằng chứng.

- Module: MD01, MD02, MD09.
- Requirement: REQ-01,02,10,11,18; [định nghĩa và acceptance](../../product-requirements.md).
- Hợp đồng chung: [business](../../business-design.md) / [feature–module](../../feature-module-map.md).

Có shell/Journey nền T05; cây K01–K23 và đường S00–S10 là thiết kế, chưa tuyên bố được app hỗ trợ đầy đủ. [Trạng thái task hiện hành](../../delivery-backlog.md) là nguồn chuẩn; mô tả trong tài liệu thiết kế không tự là bằng chứng runtime DONE.
