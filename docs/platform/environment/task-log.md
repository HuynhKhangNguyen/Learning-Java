Phạm vi là môi trường dev hiện có và terminal, không leaf sản phẩm mới; không sửa trạng thái/nguồn runtime BL-R03 đang thực thi trong chat riêng, không commit/deploy hoặc tạo thêm chat/agent.
- Plan/đầu ra: kiểm kê → đọc yêu cầu Docker/WSL và Windows feature → helper terminal theo runtime có sẵn → native checks/review. Thêm [enter-dev-shell.ps1](../../../scripts/enter-dev-shell.ps1), [hướng dẫn/evidence](development.md) và link README. Helper dùng JDK pin từ manifest, Node phù hợp, npm/npx shim trong ignored `.tools/dev-shell`; chỉ đổi environment process, không PATH/registry/profile/execution policy hệ thống hoặc tải runtime.
- Đã kiểm: Java21.0.12.1+1-LTS/javac21, Node24.19.0, npm/npx8.5.5, FE runtime check và Maven3.9.16 toolchain offline exit0. Store update là hướng chưa kiểm chứng; IT có thể cập nhật WSL hoặc bật feature VMM, remote Docker cần host được cấp.
